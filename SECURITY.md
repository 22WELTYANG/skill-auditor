# Security Policy

## Supported versions

Security fixes are provided for the latest published `0.x` release. Upgrade to
the newest release before reporting behavior that may already have been fixed.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository. Do
not open a public issue or include secrets, access tokens, or private target
content in a report.

Include the affected version, operating system, exact command, a minimal
reproducer, and the observed exit code. Reports are acknowledged as soon as
practical; remediation timing depends on severity and reproducibility.
