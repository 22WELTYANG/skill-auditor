# Security Policy

## Supported versions

Security fixes are provided for the latest published `0.x` release. Upgrade to
the newest release before reporting behavior that may already have been fixed.

## Reporting a vulnerability

Please use
[GitHub private vulnerability reporting](https://github.com/22WELTYANG/skill-auditor/security/advisories/new)
for this repository. Do not open a public issue or include secrets, access
tokens, private target content, or live malicious infrastructure in a report.

Include the affected version, operating system, exact command, a minimal
neutralized reproducer, observed exit code, `scan_status`, and expected security
boundary. Explain whether the issue can cause target execution, missed CRITICAL
behavior, trust-policy bypass, incomplete coverage to pass, unsafe installation,
credential disclosure, or CI/SARIF gating failure.

## Coordinated disclosure

Please allow the maintainer time to reproduce, fix, test, and publish an update
before public disclosure. Reports are acknowledged as soon as practical;
remediation and disclosure timing depend on severity, exploitability, and
reproducibility. Credit is offered when requested and appropriate.

False positives, missed attack patterns that do not expose a vulnerability in
the scanner itself, and public suspicious-Skill samples can use the dedicated
Issue forms after sensitive data is removed.
